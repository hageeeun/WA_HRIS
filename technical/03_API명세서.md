# [API 명세서] HRIS System (Phase 1 MVP)

> 본 문서는 **HRIS System (Phase 1 MVP)**의 화면(`02_화면설계서`) 및 기능(`03_기능정의서`) 요구사항을 바탕으로, **프론트엔드 화면과 백엔드 서버 간의 데이터 송수신 및 인터페이스 규칙**을 정의한 기획 명세서입니다.

## 1. 개요 및 공통 인터페이스 규약 (Overview & Interface Rules)

### 1.1 기본 연동 규칙 및 인증 정책 요약

|**구분**|**연동 기준 및 적용 정책**|**기획 및 비즈니스 목적**|
|---|---|---|
|**기본 경로 (Base URL)**|`/api/v1`|Phase 1 MVP 표준 엔드포인트 경로|
|**데이터 형식**|웹 표준 텍스트 데이터 포맷|JSON 기반 송수신 (단, 파일 업로드는 파일 전용, 증명서는 PDF 다운로드)|
|**로그인 인증 방식**|보안 쿠키 기반 로그인 세션 유지|브라우저에 인증 정보를 안전하게 보관하여 매 화면 이동 시 자동 검증|
|**접근 권한 제어**|2단계 권한 (`ADMIN` / `USER`)|일반 직원의 관리자 전용 화면/기능 비인가 접근을 서버에서 차단|
|**날짜 및 시간 기준**|한국 표준시 (`YYYY-MM-DD HH:mm:ss`)|출퇴근, 휴가 일자, 결재 승인 시점 등 모든 시간 데이터 KST 표기|

### 1.2 화면-서버 간 공통 데이터 응답 규칙

프론트엔드가 토스트 팝업, 안내 모달, 데이터 목록을 일관되게 그릴 수 있도록 서버 응답 항목을 표준화합니다.

|**처리 결과**|**응답 항목**|**데이터 성격**|**항목별 세부 설명 및 화면 연동 기준**|
|---|---|---|---|
|**성공 (정상 처리)**|**성공 여부** (`success`)|`True`|요청한 작업이 문제없이 완료됨을 알림|
||**결과 데이터** (`data`)|데이터/목록|화면 렌더링에 필요한 실제 정보 (내 정보, 신청 목록, 문서 상세 등)|
||**완료 메시지** (`message`)|한글 텍스트|화면 상단에 띄울 성공 알림 토스트 문구 (예: "휴가 신청이 완료되었습니다.")|
|**실패 (예외/오류)**|**성공 여부** (`success`)|`False`|입력 오류, 권한 부족 등 예외로 인해 작업이 중단됨을 알림|
||**에러 코드** (`code`)|영문 코드|개발팀과 사전 합의한 예외 상황 식별값 (예: `INSUFFICIENT_BALANCE`)|
||**안내 메시지** (`message`)|한글 텍스트|`03_UX라이팅가이드` 기준 화면에 즉시 노출할 한국어 안내 문구|

### 1.3 상황별 시스템 피드백 및 예외 정책 매핑표

기획서의 비즈니스 예외 규칙과 UX 라이팅 가이드를 연결하여 사전 정의한 표준 에러 매핑표입니다.

|**발생 상황 (비즈니스 케이스)**|**연계 기능**|**에러 식별 코드 (code)**|**화면 노출 안내 메시지 (message)**|
|---|---|---|---|
|**로그인 정보 불일치**|`LOG` 로그인|`INVALID_CREDENTIALS`|이메일 또는 비밀번호가 일치하지 않습니다.|
|**로그인 세션 만료**|공통|`UNAUTHORIZED`|로그인이 필요한 서비스입니다.|
|**관리자 메뉴 비인가 접근**|`MEM`, `SET`|`FORBIDDEN_ACCESS`|접근 권한이 없습니다.|
|**잔여 연차 초과 신청**|`VAC` 휴가 신청|`INSUFFICIENT_BALANCE`|잔여 연차 일수를 초과하여 신청할 수 없습니다.|
|**당일 출퇴근 중복 체크**|`ATT` 출근 체크|`ALREADY_CHECKED_IN`|이미 금일 출근 체크가 완료되었습니다.|
|**초대 링크 만료 (7일 초과)**|`LOG` 비밀번호 설정|`INVITATION_EXPIRED`|유효기간이 만료된 초대 링크입니다. 관리자에게 재발송을 요청해 주세요.|
|**필수값 누락 / 입력 오류**|공통 서식 작성|`INVALID_INPUT`|필수 입력 항목을 올바르게 작성해 주세요.|
|**조회 대상 리소스 없음**|`DOC`, `CRT` 상세|`RESOURCE_NOT_FOUND`|요청하신 정보를 찾을 수 없습니다.|
|**시스템 일시적 오류**|공통|`SERVER_ERROR`|일시적인 오류가 발생했습니다. 잠시 후 다시 시도해 주세요.|

## 3. 도메인별 상세 API 명세 (Detailed Specifications)

기획서의 19대 세부 기능(`FN-01` ~ `FN-19`)을 화면 구현 관점에서 정의한 상세 입·출력 명세입니다.

### 3.1 인증 및 계정 관리 모듈 (`LOG`, `MY`)

#### 1) 로그인 (`FN-01`)

- **기능 설명**: 이메일과 비밀번호를 검증하여 로그인 세션을 생성하고 사용자 기본 프로필을 반환합니다.
    
- **호출 방식**: `POST /api/v1/auth/login` (접근 권한: 전체 비로그인)
    

|**구분**|**항목명**|**데이터 성격**|**필수 여부**|**설명 및 기획 제약 조건**|
|---|---|---|---|---|
|**요청 (화면 $\rightarrow$ 서버)**|`email`|텍스트|필수|로그인 아이디 (회사 이메일 형식)|
||`password`|텍스트|필수|비밀번호|
|**응답 (서버 $\rightarrow$ 화면)**|`user_id`|고유 ID|필수|로그인한 사용자 고유 식별자|
||`name`|텍스트|필수|사용자 성명|
||`email`|텍스트|필수|사용자 이메일|
||`role`|코드값|필수|시스템 권한 (`ADMIN` / `USER`)|
||`department_name`|텍스트|선택|소속 부서명|
||`position`|텍스트|필수|직급/직책|

#### 2) 로그아웃 (`FN-02`)

- **기능 설명**: 현재 브라우저의 로그인 인증 세션 쿠키를 파기하고 로그인 화면으로 리다이렉트합니다.
    
- **호출 방식**: `POST /api/v1/auth/logout` (접근 권한: 로그인 사용자 전체)
    

|**구분**|**항목명**|**데이터 성격**|**필수 여부**|**설명 및 기획 제약 조건**|
|---|---|---|---|---|
|**요청 (화면 $\rightarrow$ 서버)**|-|-|-|별도 입력값 없음 (인증 세션 자동 전송)|
|**응답 (서버 $\rightarrow$ 화면)**|`message`|텍스트|필수|"로그아웃되었습니다."|

#### 3) 초대 비밀번호 설정 (`FN-03`)

- **기능 설명**: 관리자에게 이메일 초대장을 받은 신규 입사자가 7일 유효 토큰을 검증하고 최초 비밀번호를 등록합니다.
    
- **호출 방식**: `POST /api/v1/auth/setup-password` (접근 권한: 초대 링크 보유자)
    

|**구분**|**항목명**|**데이터 성격**|**필수 여부**|**설명 및 기획 제약 조건**|
|---|---|---|---|---|
|**요청 (화면 $\rightarrow$ 서버)**|`token`|텍스트|필수|이메일 링크에 포함된 1회용 고유 토큰|
||`password`|텍스트|필수|신규 비밀번호 (영문/숫자/특수문자 포함 8자 이상)|
|**응답 (서버 $\rightarrow$ 화면)**|`message`|텍스트|필수|"비밀번호 설정이 완료되었습니다. 로그인해 주세요."|

#### 4) 내 프로필 조회 (`FN-04`)

- **기능 설명**: 화면 상단 GNB 프로필 영역 및 마이페이지에서 내 인사 기본 정보를 조회합니다.
    
- **호출 방식**: `GET /api/v1/users/me` (접근 권한: 로그인 사용자 전체)
    

|**구분**|**항목명**|**데이터 성격**|**필수 여부**|**설명 및 기획 제약 조건**|
|---|---|---|---|---|
|**요청 (화면 $\rightarrow$ 서버)**|-|-|-|별도 입력값 없음 (로그인 세션 기반 조회)|
|**응답 (서버 $\rightarrow$ 화면)**|`name`|텍스트|필수|임직원 성명|
||`employee_number`|텍스트|필수|사번|
||`email`|텍스트|필수|회사 이메일|
||`role`|코드값|필수|시스템 권한 (`ADMIN` / `USER`)|
||`department_name`|텍스트|선택|소속 부서명|
||`position`|텍스트|필수|직급/직책|
||`phone`|텍스트|선택|휴대폰 연락처|
||`join_date`|날짜|필수|입사일자 (`YYYY-MM-DD`)|
||`profile_image_url`|URL|선택|프로필 이미지 경로|

#### 5) 내 비밀번호 변경 (`FN-05`)

- **기능 설명**: 마이페이지에서 현재 비밀번호를 검증한 후 신규 비밀번호로 갱신합니다.
    
- **호출 방식**: `PATCH /api/v1/users/me/password` (접근 권한: 로그인 사용자 전체)

|**구분**|**항목명**|**데이터 성격**|**필수 여부**|**설명 및 기획 제약 조건**|
|---|---|---|---|---|
|**요청 (화면 $\rightarrow$ 서버)**|`cert_type`|코드값|필수|서식 종류 (`EMPLOYMENT`: 재직, `CAREER`: 경력)|
||`purpose`|텍스트|필수|발급 용도 (예: 금융기관 제출용)|
|**응답 (서버 $\rightarrow$ 화면)**|`issue_number`|텍스트|필수|발급 고유 번호 (예: `CRT-20260815-001`)|
||`verification_code`|텍스트|필수|위변조 방지 12자리 검증 코드|
||`pdf_download_url`|파일/스트림|필수|브라우저 즉시 인쇄/다운로드용 A4 PDF 바이너리|

### 3.6 구성원 및 회사 설정 모듈 (`MEM`, `SET`)

#### 1) 신규 구성원 초대 (`FN-19`)

- **기능 설명**: 관리자가 신규 입사자의 이메일, 기본 부서, 직급을 등록하고 7일 유효 초대 메일을 발송합니다.
    
- **호출 방식**: `POST /api/v1/admin/members/invite` (접근 권한: 최고관리자 `ADMIN`)
    

|**구분**|**항목명**|**데이터 성격**|**필수 여부**|**설명 및 기획 제약 조건**|
|---|---|---|---|---|
|**요청 (화면 $\rightarrow$ 서버)**|`email`|텍스트|필수|초대 대상자 이메일|
||`name`|텍스트|필수|입사자 성명|
||`employee_number`|텍스트|필수|사번|
||`department_id`|고유 ID|선택|소속 부서 식별자|
||`position`|텍스트|필수|직급/직책|
||`join_date`|날짜|필수|입사일자|
||`role`|코드값|필수|부여 권한 (`USER` 또는 `ADMIN`)|
|**응답 (서버 $\rightarrow$ 화면)**|`message`|텍스트|필수|"초대 메일이 정상적으로 발송되었습니다."|

#### 2) 회사 설정 및 대표 직인 등록

- **기능 설명**: 관리자가 회사 상호명, 대표자명, 사업자번호를 수정하고 투명 배경 대표 직인 PNG 이미지를 업로드합니다.
    
- **호출 방식**: `PATCH /api/v1/admin/settings/company` (접근 권한: 최고관리자 `ADMIN`)
    

|**구분**|**항목명**|**데이터 성격**|**필수 여부**|**설명 및 기획 제약 조건**|
|---|---|---|---|---|
|**요청 (화면 $\rightarrow$ 서버)**|`company_name`|텍스트|필수|회사 상호명|
||`ceo_name`|텍스트|필수|대표이사 성명|
||`business_number`|텍스트|필수|사업자 등록번호|
||`company_address`|텍스트|필수|회사 주소|
||`seal_image`|이미지 파일|선택|직인 PNG 파일 (투명 배경, 최대 2MB)|
|**응답 (서버 $\rightarrow$ 화면)**|`seal_image_url`|URL|선택|저장된 직인 이미지 경로|
