# [화면설계서 (UI/UX Specification)] # HRIS System (Phase 1 MVP)

## 1. 문서 식별자 체계 정의 (ID Mapping Standard)

추후 작성될 **기능정의서(Feature Spec)** 및 HR 운영정책서(Business Rule)와의 완벽한 1:1 및 1:N 추적성을 보장하기 위해 본 문서에서 사용되는 식별자 체계를 다음과 같이 정의합니다.

### 1.1 식별자 구분 체계
| **구분**    | **Prefix** | **예시**       | **설명**                          |
| --------- | ---------- | ------------ | ------------------------------- |
| **화면 ID** | `SCR-`     | `SCR-LOG-01` | 사용자 인터페이스(UI) 화면 단위 식별자         |
| **기능 ID** | `FN-`      | `FN-VAC-01`  | 기능정의서에서 다룰 세부 동작 및 로직 단위 식별자    |
| **정책 ID** | `POL-`     | `POL-VAC-01` | 운영정책서에서 다룰 업무 규칙 및 수식 계산 단위 식별자 |

### 1.2 모듈별 Prefix 정의

- **`LOG`** : 계정 및 인증 (Login / Auth)
    
- **`MY`** : 내 정보 설정 (My Profile)
    
- **`ATT`** : 근태 관리 (Attendance)
    
- **`VAC`** : 휴가 관리 (Vacation)
    
- **`DOC`** : 결재 문서 관리 (Approval Documents)
    
- **`CRT`** : 증명서 발급 (Certificates)
    
- **`MEM`** : 구성원 관리 (Members)
    
- **`SET`** : 회사 설정 (Company Settings)

## 2. 정보 구조 (IA: Information Architecture)

### 2.1 사이드바 그룹형 네비게이션 구조 (Depth 1 헤더 / Depth 2 서브메뉴)

- **Depth 1**: 클릭 이동이 없는 고정 카테고리 헤더 라벨
    
- **Depth 2**: 실제 해당 화면으로 라우팅되는 클릭 메뉴 아이템
    
- **Bottom**: 개인 계정 유틸리티 카드 및 시스템 액션

## 3. 글로벌 공통 레이아웃 명세 (Global Layout Specification)

본 시스템은 PC 웹 브라우저 환경에 최적화된 **좌측 고정 사이드바(Left Navigation Bar) + 우측 메인 콘텐츠 영역**의 2분할 레이아웃 표준을 따릅니다.

```
+-----------------------------------------------------------------------------------------------+
|  [사이드바 (LNB)] (고정 폭: 240px)                  |  [메인 콘텐츠 영역 (Main Content Area)]                     |
|                                                                            |                                                                                         |
|  +---------------------------------------+  |  +-------------------------------------------+        |
|  | [3.2 상단] 등록 회사명                                 |  |  |  페이지 타이틀 (Page Header)                                |  |
|  +---------------------------------------+  |  +-------------------------------------------+       |
|  | [3.1 메뉴] 그룹형 사이드바 네비게이션        |   |   |                                                                                 |  |
|  |   - 근태 (출퇴근 기록, 전사 현황)                  |   |   |  본문 콘텐츠 (Table, Form, Cards 등)                   |  |
|  |   - 휴가 (휴가 내역, 휴가 결재)                     |   |   |                                                                                 |  |
|  |   - 문서 (결재 문서, 증명서 발급)                  |   |   |                                                                                 |  |
|  |   - 구성원 (구성원 조회, 구성원 관리)           |   |   |                                                                                 |  |
|  |   - 설정 (회사 정보)                                      |   |   |                                                                                 |  |
|  +---------------------------------------+  |  |                                                                                  |  |
|  | [3.2 하단] 2단 프로필 & 액션 카드              |   |   |                                                                                 |  |
|  +---------------------------------------+  |  +-------------------------------------------+        |
+-----------------------------------------------------------------------------------------------+
```

### 3.1 GNB / LNB 고정 사이드바 레이아웃

- **화면 규격**: PC 웹 브라우저 최적화, 스크롤 시에도 항상 노출되는 좌측 고정 사이드바 형태
    
- **메뉴 구성 원칙**:
    
    - **대메뉴 (Depth 1)**: 클릭 이동이 없는 섹션 구분용 헤더 라벨
        
    - **소메뉴 (Depth 2)**: 클릭 시 해당 화면으로 이동. 선택된 활성 메뉴는 시각적 강조 처리
        
    - **권한 제어**: `[ADMIN]` 표기 메뉴는 관리자 권한 계정 로그인 시에만 노출되며, 일반 임직원(`USER`)에게는 완전히 숨김 처리
        

```
┌───────────────────────────────────────┐
│  (주)알파컴퍼니                                                                  │  ◀ 회사명 (SCR-SET-01 연동)
├───────────────────────────────────────┤
│  근태                                                                                   │
│    ∙ 출퇴근 기록                         [SCR-ATT-01]                 │
│    ∙ 전사 근태 현황    [ADMIN] [SCR-ATT-02]                 │
│                                                                                            │
│  휴가                                                                                   │
│    ∙ 휴가 내역                          [SCR-VAC-01]                  │
│    ∙ 휴가 결재         [ADMIN] [SCR-VAC-02]                  │
│                                                                                           │
│  문서                                                                                  │
│    ∙ 결재 문서                          [SCR-DOC-01]                 │
│    ∙ 증명서 발급                       [SCR-CRT-01]                 │
│                                                                                           │
│  구성원                                                                              │
│    ∙ 구성원 조회                        [SCR-MEM-01]              │
│    ∙ 구성원 관리       [ADMIN] [SCR-MEM-02]              │
│                                                                                          │
│  설정                         [ADMIN]                                         │
│    ∙ 회사 정보                            [SCR-SET-01]               │
└───────────────────────────────────────┘
```

### 3.2 상단 회사명 및 하단 프로필 카드 규격

#### 1) 사이드바 상단: 회사명 영역

- **표시 내용**: [SCR-SET-01] 회사 정보에 등록된 `회사명(상호)`을 동적으로 바인딩하여 표출.
    
- **기본값**: 등록된 회사명이 없을 경우 기본 텍스트(`Mini HR`) 노출.
    
- **인터랙션**: 클릭 시 메인 대시보드 역할인 **[SCR-ATT-01 출퇴근 기록]** 화면으로 이동.
    

#### 2) 사이드바 하단: 프로필 카드 영역

사용자 기본 정보 노출과 개인화 액션(내 정보, 로그아웃)을 결합한 컴팩트 카드 규격입니다.

```
┌───────────────────────────────────────┐
│  ┌───────┐  홍길동                                                        │  ◀ [1줄] 프로필 아바타 + 성명
│  │   👤        │  개발팀 | 대리                                              │  ◀ [2줄] 소속팀 | 직급
│  └───────┘                                                                     │
│  +------------------------------------------------+  │
│  |  [ ⚙️ 내 정보 ] (SCR-MY-01)   |   [ 🚪 로그아웃 ]     |  │  ◀ [3줄] 아이콘 유틸리티 버튼
│  +-------------------------------------------------+  │
└────────────────────────────────────────┘
```

- **프로필 아바타**: 사용자 등록 프로필 사진 표출 (미등록 시 기본 실루엣 아이콘 노출)
    
- **사용자 정보**:
    
    - 1줄: **이름** (예: `홍길동`)
        
    - 2줄: **소속팀 | 직급** (예: `개발팀 | 대리`)
        
- **하단 액션 버튼**:
    
    - **[ ⚙️ 내 정보 ]**: 클릭 시 `SCR-MY-01` 내 정보 관리 화면 호출 (프로필 사진, 연락처, 비밀번호 변경).
        
    - **[ 🚪 로그아웃 ]**: 클릭 시 로그아웃 및 `SCR-LOG-01` 로그인 화면으로 이동.
        

### 3.3 공통 인터랙션 및 상태 표기 규칙

- **레이어 모달 동작**: `ESC` 키 입력 또는 [취소] 클릭 시 작성 중인 데이터는 저장되지 않고 모달이 닫힘.
    
- **목록 조회 및 Empty State**: 조회된 데이터가 없을 경우 `"내역이 존재하지 않습니다."` 공통 안내 문구 표출.
    
- **상태 표기 표준**: 시스템 전반의 상태 텍스트는 4가지 표준 규격으로 일관되게 표출.
    
    - `대기` (초대 대기, 결재 대기 등)
        
    - `승인` (결재 완료, 계정 정상, 발급 완료 등)
        
    - `반려` (결재 반려, 계정 정지 등)
        
    - `취소` (신청자 본인 직접 취소)

## 4. 핵심 사용자 동선 다이어그램 (User Flow)

### Flow 1. 계정 초대, 최초 가입 및 내 정보 설정 Flow

```
[관리자] SCR-MEM-02 화면/모달 진입
  └─ [초대하기] 클릭 ➔ 이름/이메일/소속/직급/초기연차 입력 ➔ 초대 메일 발송 (상태: INITIALIZED)
       └─ [임직원] 수신한 초대 이메일 내 링크 클릭
            └─ SCR-LOG-02 비밀번호 설정 화면 이동
                 └─ 비밀번호 입력 및 확인 ➔ 가입 완료 (상태: ACTIVE)
                      └─ SCR-LOG-01 로그인 ➔ 출퇴근 기록(SCR-ATT-01) 메인 진입
                           └─ 하단 프로필 [내 정보(SCR-MY-01)] 진입 ➔ 프로필 사진 등록 및 연락처 수정
```

### Flow 2. 출퇴근 기록 및 임직원 직접 근태 정정 Flow

```
[임직원] SCR-ATT-01 출퇴근 기록 메인 진입
  ├─ [출근하기] 클릭 ➔ 출근 시각 기록 및 버튼 상태 '퇴근하기'로 전환
  └─ [퇴근하기] 클릭 ➔ 퇴근 시각 기록 및 당일 총 근무시간 자동 계산

[임직원 본인 근태 수정 시]
  └─ 월별 내역에서 수정할 일자 선택 ➔ [수정] 클릭 ➔ 수정 시각 및 수정 사유(필수) 입력
       └─ [저장] 클릭 ➔ 출퇴근 기록 즉시 갱신 및 시스템 감사 로그(Audit Log) 영구 보존

[관리자 모니터링]
  └─ SCR-ATT-02 전사 근태 현황 진입 ➔ 전사 출퇴근 현황 및 직원의 근태 수정 사유/이력 조회
```

### Flow 3. 휴가 신청, 본인 취소 및 관리자 승인/반려 Flow

```
[임직원] SCR-VAC-01 휴가 내역 진입
  └─ [ + 휴가 신청 ] 클릭 ➔ 모달 폼 호출 (유형: 연차/오전반차/오후반차, 기간, 사유 입력)
       └─ 가용 연차 잔여량 및 공휴일/주말 제외 일수 자동 검증
            ├─ [검증 통과] 신청 완료 (상태: REQUESTED, 잔여 연차는 유지되나 가용 연차 일시 차감)
            └─ [본인 취소] 신청 목록에서 [취소] 클릭 ➔ 상태 CANCELED 변경 (승인건 취소 시 잔여 연차 복구)

[관리자] SCR-VAC-02 휴가 결재 진입
  ├─ [승인] 클릭 ➔ 1단계 최종 승인 완료 (상태: APPROVED, 실제 잔여 연차 정식 차감)
  └─ [반려] 클릭 ➔ 반려 사유 필수 입력 팝업 ➔ 반려 확정 (상태: REJECTED, 연차 미차감)
```

### Flow 4. 결재 문서(교육/지출) 작성 및 1단계 결재/직인 자동 날인 Flow

```
[임직원] SCR-DOC-01 결재 문서 진입 ➔ [ + 결재 문서 작성 ] 클릭
  └─ SCR-DOC-02 기안 작성 화면 이동 ➔ 문서 구분(교육신청서 / 지출결의서), 제목, 금액, 상세 내용 작성
       └─ [제출하기] 클릭 ➔ 제출 완료 (상태: REQUESTED) ➔ 내 기안함 목록 이동

[관리자] SCR-DOC-01 [결재 관리 탭] 진입 ➔ 문서 선택하여 SCR-DOC-03 상세 화면 이동
  ├─ [승인] 클릭 ➔ 1단계 결재 승인 (상태: APPROVED) ➔ 등록된 회사 직인(인감) 이미지 자동 날인
  └─ [반려] 클릭 ➔ 반려 사유 필수 작성 팝업 ➔ 반려 확정 (상태: REJECTED)
```

### Flow 5. 증명서(재직/경력) 무결재 즉시 PDF 발급 및 관리자 이력 조회 Flow

```
[임직원] SCR-CRT-01 증명서 발급 진입
  └─ 증명서 구분(재직증명서 / 경력증명서) 선택 ➔ 제출처 및 발급 용도 입력
       └─ [즉시 발급 (PDF)] 클릭 ➔ 회사 정보 및 직인이 자동 날인된 PDF 문서 즉시 생성/다운로드
            └─ 증명서 발급 이력 데이터베이스 자동 저장

[관리자] SCR-CRT-01 [발급 이력 탭] 진입
  └─ 전사 임직원의 증명서 발급 일시, 발급자, 문서 종류, 제출처/용도 이력 목록 조회
```

### Flow 6. 회사 기본 정보 및 직인(인감) 이미지 등록 Flow

```
[관리자] SCR-SET-01 회사 정보 진입
  ├─ 회사 기본 정보(회사명, 사업자번호, 대표자명, 사업장 주소 등) 입력 및 [저장]
  │    └─ 저장된 회사명은 사이드바 상단 네비게이션에 즉시 반영
  └─ 회사 직인(인감) 이미지 파일(PNG) 업로드 및 미리보기 확인 ➔ [저장]
       └─ 결재 승인 문서(SCR-DOC-03) 및 증명서 발급(SCR-CRT-01) PDF 생성 시 해당 인감 자동 날인
```
