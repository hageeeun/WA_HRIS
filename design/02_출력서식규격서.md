# [출력 서식 규격서] 증명서 및 결재 문서 A4 PDF 서식 명세

> 본 문서는 **HRIS System (Phase 1 MVP)**에서 생성되는 모든 증명서 및 결재 완료 문서의 **A4 PDF 변환 및 인쇄(Print) 레이아웃 규격**을 정의합니다. 브라우저 인쇄(`window.print()`)와 PDF 생성 엔진 모두에서 왜곡 없이 1:1 정비율로 출력되도록 설계되었습니다.

## 1. 개요 및 공통 인쇄 파운데이션 (Overview & Print Foundations)

### 1.1 문서 목적 및 적용 대상

- **문서 목적**: A4 용지 규격에 최적화된 인쇄 스타일시트(`@media print`) 및 PDF 렌더링 좌표 기준 수립
    
- **적용 대상 서식**:
    
    1. **증명서 모듈 (CRT)**: 재직증명서, 경력증명서
        
    2. **결재 문서 모듈 (DOC)**: 일반 품의서, 지출 품의서, 휴가 신청서 인쇄 뷰
        

### 1.2 A4 용지 규격 및 여백 (Page Setup & Margins)

인쇄 시 프린터의 하드웨어 마진(물리적 여백) 및 PDF 뷰어의 여백 잘림을 방지하기 위해 표준 여백을 적용합니다.

```
┌─────────────────────────────────────────────────────────────┐
│ ◀─────────────────────── 210mm ───────────────────────────▶ │
│ ┌─────────────────────────────────────────────────────────┐ ▲
│ │ Top Margin: 25mm                                        │ │
│ │ ┌─────────────────────────────────────────────────────┐ │ │
│ │ │                                                     │ │ │
│ │ │                                                     │ │ │
│ │ │           인쇄 가능 유효 영역 (Printable Area)        │ │ │
│ │ │           - 폭 (Width): 170mm                       │ │ 297mm
│ │ │           - 높이 (Height): 247mm                     │ │ │
│ │ │                                                     │ │ │
│ │ │                                                     │ │ │
│ │ └─────────────────────────────────────────────────────┘ │ │
│ │ Bottom Margin: 25mm                                     │ │
│ └─────────────────────────────────────────────────────────┘ ▼
│   ◀ Left: 20mm ▶                               ◀ Right: 20mm ▶
└─────────────────────────────────────────────────────────────┘
```

|**구분**|**규격 수치**|**CSS/인쇄 설정 기준**|
|---|---|---|
|**용지 표준**|ISO 216 A4|`210mm × 297mm` (세로 Portrait 방향 고정)|
|**상/하 여백 (Top / Bottom)**|`25mm` (약 94.5px)|상단 헤더 및 하단 발급 검증 영역 확보|
|**좌/우 여백 (Left / Right)**|`20mm` (약 75.6px)|바인더 철 및 여백 안정성 확보|
|**유효 인쇄 영역**|`170mm × 247mm`|모든 표와 텍스트가 위치하는 실제 캔버스 영역|

### 1.3 인쇄 전용 타이포그래피 & 컬러 시스템

인쇄물은 화면(Screen)과 달리 **`pt` (Point)** 단위를 기준으로 하며, 잉크 번짐 방지와 시인성을 위해 **흑백(Monochrome)을 기본**으로 합니다.

#### 1) 타이포그래피 스케일 (Pretendard 단일 서체)

- **기본 폰트**: `Pretendard`, `sans-serif` (인쇄 시 시스템 폰트 대체 지원)
    

|**텍스트 스타일**|**Size (pt)**|**Weight**|**Line-Height**|**자간 (Tracking)**|**주요 사용 위치**|
|---|---|---|---|---|---|
|**문서 대제목 (Title)**|**20pt**|Bold (700)|28pt|0.15em|서식 상단 제목 (예: "재 직 증 명 서")|
|**섹션 / 소제목**|**12pt**|SemiBold (600)|18pt|0|결재선 헤더, 주요 항목 타이틀|
|**테이블 헤더 / 라벨**|**10pt**|SemiBold (600)|15pt|0|표 좌측 항목명 (성명, 부서, 직급 등)|
|**테이블 본문 (Data)**|**10pt**|Regular (400)|15pt|0|표 내부 실제 기재 데이터|
|**법정 증명 문구**|**12pt**|SemiBold (600)|20pt|0.05em|"위와 같이 재직하고 있음을 증명합니다."|
|**하단 메타 / 각주**|**8.5pt**|Regular (400)|12pt|0|문서 번호, 시스템 발급 타임스탬프|

#### 2) 컬러 규격

- **텍스트 & 라인 (K100 Black)**: `#000000` (완전 흑색 인쇄)
    
- **테이블 헤더 배경 (Gray 5%)**: `#F4F4F5` (연한 무채색 틴트)
    
- **테이블 경계선 (Border)**:
    
    - 외곽/헤더 강조선: `1.0pt solid #000000`
        
    - 내부 구분선: `0.5pt solid #D4D4D8`
        
- **유일한 컬러 예외 (대표 직인/인감)**: `#DC2626` (Red-600) 또는 정품 인주 색상 (`#B91C1C`)


### 1.4 인쇄 및 PDF 변환 공통 요구사항 (Print Requirements)

| **요구사항 항목**          | **기획 / 디자인 적용 기준**                                                                                     | **개발 전달 참고 사항**                               |
| -------------------- | ------------------------------------------------------------------------------------------------------ | --------------------------------------------- |
| **1. UI 요소 비노출**     | 인쇄/PDF 출력물에는 사이드바, 헤더, 인쇄 버튼을 일체 숨기고 **순수 서식만 렌더링**                                                    | `.no-print { display: none; }`                |
| **2. 서식별 페이지 분할 정책** | • **증명서/휴가서**: A4 1장 고정 (`page-break-inside: avoid`)<br><br>• **교육/품의서**: 본문 길이에 따라 2페이지 이상 유연하게 확장 허용 | 서식별 클래스 분기 처리                                 |
| **3. 표/블록 쪼개짐 방지**   | 다장 출력 시 표의 중간 행이나 텍스트 블록이 **페이지 경계선에서 반으로 잘리지 않도록** 다음 페이지로 자동 이관                                      | `tr, .section-block { break-inside: avoid; }` |
| **4. 페이지 번호 자동 표기**  | 2페이지 이상 문서의 경우 하단 중앙에 `- N / Total -` 형태의 페이지 번호 표출                                                    | `@bottom-center` 또는 PDF 엔진 변수 바인딩             |
| **5. 표 배경색 강제 유지**   | 브라우저 설정과 무관하게 테이블 헤더 연회색(`#F4F4F5`) 배경 인쇄 강제                                                           | `print-color-adjust: exact`                   |

## 2. 증명서 서식 규격 (재직/경력증명서)

### 2.1 대상 서식 및 레이아웃 개요

- **대상 서식**: **재직증명서**, **경력증명서**
    
- **페이지 규칙**: **1페이지 고정** (내용이 길어져도 무조건 A4 1장 안에 쏙 들어가도록 구성)
    
- **A4 인쇄 서식 미리보기**

```
┌─────────────────────────────────────────────────────────────┐
│ 제 CRT-20260815-001 호                                      │  <-- 상단 발급번호 (작은 글씨)
│                                                             │
│                       재 직 증 명 서                         │  <-- 문서 제목 (가장 큰 굵은 글씨)
│                                                             │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │  1. 인적 사항                                            │ │  <-- 소제목
│ ├──────────────┬──────────────┬──────────────┬────────────┤ │
│ │ 성        명 │ 홍길동       │ 생 년 월 일  │ 1990.01.01 │ │
│ ├──────────────┼──────────────┴──────────────┴────────────┤ │
│ │ 주        소 │ 서울특별시 강남구 테헤란로 123           │ │  <-- 가로 3칸 합침
│ └──────────────┴──────────────────────────────────────────┘ │
│                                                             │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │  2. 재직 사항 (경력증명서의 경우: 2. 경력 사항)          │ │
│ ├──────────────┬──────────────┬──────────────┬────────────┤ │
│ │ 소 속 부 서  │ 개발팀       │ 직        급 │ 선임연구원 │ │
│ ├──────────────┼──────────────┴──────────────┴────────────┤ │
│ │ 재 직 기 간  │ 2024.01.01 ~ 현재 (재직중)               │ │  <-- 재직자 표기
│ │ (경력증명서) │ [ 2022.01.01 ~ 2025.12.31 (총 4년 0개월) ]│ │  <-- 퇴사자 표기
│ ├──────────────┼──────────────────────────────────────────┤ │
│ │ 담 당 업 무  │ 웹 서비스 UI 개발 및 디자인 시스템 구축  │ │
│ ├──────────────┼──────────────────────────────────────────┤ │
│ │ 발 급 용 도  │ 금융기관 제출용 (대출 심사)              │ │
│ └──────────────┴──────────────────────────────────────────┘ │
│                                                             │
│                                                             │
│             위와 같이 재직하고 있음을 증명합니다.           │  <-- 법정 증명 문구 (중앙 정렬)
│                                                             │
│                                                             │
│                      2026년 08월 15일                       │  <-- 발급일자
│                                                             │
│                주식회사 에이치알컴퍼니                      │  <-- 회사명 (굵은 글씨)
│                대표이사   김  대  표   [ 회사 직인 ]        │  <-- 대표자명 + 도장 겹침
└─────────────────────────────────────────────────────────────┘
```

### 2.2 상단 헤더 및 문서 제목

| **항목**       | **화면/인쇄 표기 형식**                                | **실제 예시**            | **위치 및 스타일 규칙**                        |
| ------------ | ---------------------------------------------- | -------------------- | -------------------------------------- |
| **문서 발급 번호** | 제 `[문서 고유번호]` 호                                | 제 CRT-20260815-001 호 | 좌측 상단 배치, 작은 글씨(8.5pt), 검정색            |
| **문서 제목**    | • 재직: **재 직 증 명 서**<br><br>• 경력: **경 력 증 명 서** | **재 직 증 명 서**        | 중앙 정렬, 가장 큰 굵은 글씨(20pt Bold), 글자 밑줄 표시 |

### 2.3 표 세부 내용 및 자동 입력 규칙

- **표 스타일**: 바깥 테두리는 진한 검정선(1pt), 안쪽 칸 구분선은 연한 회색선(0.5pt)
    
- **칸 배경색**: 왼쪽 '항목명' 칸은 연한 회색 배경, 오른쪽 '내용' 칸은 흰색 배경

#### 1) 1. 인적 사항 표

|**항목명**|**들어가는 실제 내용**|**표 배치 규칙**|
|---|---|---|
|**성 명**|신청자 이름 (예: 홍길동)|좌측 정렬|
|**생 년 월 일**|생년월일 8자리 (예: 1990년 01월 01일)|좌측 정렬|
|**주 소**|신청자 거주지 주소 (예: 서울특별시 강남구 테헤란로 123)|가로 3칸을 하나로 합쳐서 넓게 표기|

#### 2) 2. 재직 / 경력 사항 표

| **항목명**      | **들어가는 실제 내용**                                                                       | **표 배치 규칙 및 분기 기준**   |
| ------------ | ------------------------------------------------------------------------------------ | --------------------- |
| **소 속 부 서**  | 소속 부서명 (예: 개발팀, 경영지원팀)                                                               | 좌측 정렬                 |
| **직 급**      | 직급/직책 (예: 선임연구원, 팀장)                                                                 | 좌측 정렬                 |
| **재직(경력)기간** | • **재직증명서 (재직자)**: `입사일 ~ 현재 (재직중)`<br><br>• **경력증명서 (퇴사자)**: `입사일 ~ 퇴사일 (총 O년 O개월)` | 가로 3칸을 합쳐서 한 줄로 길게 표기 |
| **담 당 업 무**  | 담당 직무 상세 (예: 웹 프론트엔드 개발 및 시스템 운영)                                                    | 가로 3칸 합침              |
| **발 급 용 도**  | 신청 시 입력한 용도 (예: 금융기관 제출용, 관공서 제출용)                                                   | 가로 3칸 합침              |

### 2.4 증명 문구 및 발급 일자

- **공식 증명 문구**:
    
    - 재직증명서: **"위와 같이 재직하고 있음을 증명합니다."**
        
    - 경력증명서: **"위와 같이 재직(경력)하였음을 증명합니다."**
        
    - 위치: 표 아래 중앙 정렬, 상하 여백을 넉넉히 주어 시각적으로 강조
        
- **발급 일자**: 발급 당일 날짜 표기 (예: `2026년 08월 15일`), 중앙 정렬
    

### 2.5 회사 정보 및 대표 직인(도장) 찍히는 위치

회사의 공식 직인(인감) 이미지가 대표이사 이름 위에 자연스럽게 겹치도록 배치합니다.

```
                  주식회사 에이치알컴퍼니               <-- 굵은 글씨
                                       ┌──────────┐
                  대표이사   김  대  표│ [직  인] │    <-- 이름 끝 글자에 겹쳐서 날인
                                       └──────────┘
```

- **회사명(상호)**: 회사 등록 상호명 표기 (예: 주식회사 에이치알컴퍼니)
    
- **대표자명**: `대표이사 김대표` (글자 사이 간격을 넓혀 품격 있게 배치)
    
- **도장(직인) 날인 규칙**:
    
    - **도장 이미지**: 배경이 투명한 빨간색 인감 이미지
        
    - **도장 크기**: 가로/세로 약 `2cm × 2cm` (인쇄 시 실제 도장 크기)
        
    - **찍히는 위치**: 대표이사 이름의 **'마지막 글자(표)' 위에 도장의 왼쪽 절반이 살짝 겹치도록** 얹음 (실제 서류에 도장 찍는 느낌 구현)


## 3. 결재 문서(품의서/신청서) 출력 서식 규격

### 3.1 대상 서식 및 레이아웃 개요

- **대상 서식**: **일반 품의서**, **지출 품의서**, **교육 신청서**, **휴가 신청서**
    
- **페이지 규칙**:
    
    - **휴가 신청서**: **1페이지 고정** (내용이 짧으므로 단일 페이지 완결)
        
    - **품의서 / 교육 신청서**: **가변 다장형** (본문이나 상세 커리큘럼 내용이 길어지면 자연스럽게 2페이지 이상으로 확장)
        
- **A4 인쇄 서식 미리보기 (1페이지 상단 기준)**

```
┌─────────────────────────────────────────────────────────────┐
│ 제 DOC-20260815-004 호                                      │
│                                                             │
│                      지 출 품 의 서                          │  <-- 문서 제목
│                                                             │
│                                        ┌──────┬──────┐      │
│                                        │ 기안 │ 승인 │      │  <-- 2단 결재선

│                                        │홍길동│[직인]│      │
│                                        ├──────┼──────┤      │
│                                        │08/15 │08/15 │      │
│                                        └──────┴──────┘      │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │  1. 기본 정보                                            │ │
│ ├──────────────┬──────────────┬──────────────┬────────────┤ │
│ │ 기   안   자 │ 홍길동       │ 소 속 부 서  │ 개발팀     │ │
│ ├──────────────┼──────────────┼──────────────┼────────────┤ │

│ └──────────────┴──────────────────────────────────────────┘ │
│                                                             │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │  2. 품의 내용 (교육신청서의 경우: 2. 교육 상세 내용)     │ │
│ ├──────────────┬──────────────────────────────────────────┤ │
│ │ 품 의 제 목  │ 클라우드 인프라 아키텍처 교육 참가 건    │ │
│ ├──────────────┼──────────────────────────────────────────┤ │
│ │ 품 의 금 액  │ 금 일백오십만원정 (₩ 1,500,000)          │ │  <-- 금액 한글 병기
│ ├──────────────┼──────────────────────────────────────────┤ │
│ │              │ 1. 교육 개요                             │ │
│ │              │ - 과정명: 클라우드 실무 아키텍처 마스터  │ │
│ │              │ - 교육 기관: 한국소프트웨어협회          │ │
│ │ 상 세 내 역  │ - 교육 기간: 2026.09.01 ~ 2026.09.03     │ │  <-- 내용 길이에 따라
│ │              │                                          │ │      유연하게 확장
│ │              │ 2. 기대 효과                             │ │
```

### 3.2 우측 상단 결재선 (결재 도장 박스) 규격

결재 문서는 회사의 대표 1단계 단선 결재 구조를 가지며, 항상 **1페이지 우측 상단에 고정 배치**됩니다.

```
                    ┌────────────┬────────────┐
                    │   기  안   │   승  인   │   <-- 헤더 (연회색 배경, 9pt SemiBold)
                    ├────────────┼────────────┤
                    │   홍 길 동 │  ┌──────┐  │   <-- 본문 높이: 48px
                    │            │  │[직인]│  │       (승인 시 대표 직인 자동 날인)
                    │            │  └──────┘  │
                    ├────────────┼────────────┤
                    │ 2026.08.15 │ 2026.08.15 │   <-- 하단 결재일자 (8.5pt Regular)
                    └────────────┴────────────┘
```

- **결재선 전체 크기**: 가로 약 `50mm`, 세로 `25mm`
    
- **칸 구성**:
    
    - **기안 칸**: 기안자 이름 + 기안 일자 (문서 생성 시 자동 입력)
        
    - **승인 칸**:
        
        - 승인 전(대기 상태): 빈 칸 유지
            
        - 승인 완료 시: **대표자 공식 직인(인감 이미지) 자동 날인** + 최종 승인 일자 표기
            
- **직인 이미지 크기**: 가로/세로 약 `15mm × 15mm` (결재 칸 크기에 맞게 쏙 들어가는 미니 규격)

### 3.4 2페이지 이상 다장 출력 시 레이아웃 처리 규칙

1. **상단 결재선 고정**:
    
    - 결재 도장 박스는 **무조건 첫 번째 페이지(1P)에만 출력**되며, 2페이지부터는 본문 내용만 이어서 출력됩니다.
        
2. **표 중간 잘림 방지**:
    
    - 본문 글이나 표의 한 칸이 종이 맨 밑에 걸려 글자 윗부분만 찍히고 아랫부분이 다음 장으로 쪼개지는 현상을 방지하여, **해당 문단/블록 전체가 깔끔하게 2페이지 첫 줄로 넘어가도록** 구성합니다.
        
3. **하단 중앙 페이지 번호**:
    
    - 총 출력 페이지가 2페이지 이상일 때만 하단 중앙에 **`- 1 / 2 -`**, **`- 2 / 2 -`** 형태로 전체 페이지 수를 자동 표기합니다.
        

## 4. 직인(인감) 렌더링 & 위변조 방지 규격 (Seal & Security)

### 4.1 직인 이미지 에셋 규격

- **이미지 포맷**: 뒷배경이 투명하게 뚫린 빨간색 인감 이미지 (`투명 배경 PNG` 권장)
    
- **해상도**: A4 인쇄 시 테두리가 깨지지 않도록 선명한 고해상도(300 DPI) 이미지 등록 권장
    
- **서식별 출력 크기**:
    
    - **증명서 하단용 (큰 도장)**: 가로/세로 약 `21mm × 21mm` (`80px × 80px`)
        
    - **결재선 승인 칸용 (작은 도장)**: 가로/세로 약 `15mm × 15mm` (`56px × 56px`)
        

### 4.2 하단 위변조 방지 및 출력 메타데이터

모든 인쇄물/PDF 최하단에는 문서의 신뢰성을 보장하기 위해 시스템 발급 정보가 한 줄로 작게 출력됩니다.

```
┌─────────────────────────────────────────────────────────────┐
│ [문서검증코드: HR-9A82-F41C]  발급일시: 2026.08.15 14:30:22  시스템: My-HR │
└─────────────────────────────────────────────────────────────┘
```

- **문서 검증 코드**: 발급 시 생성되는 고유 암호화 난수 코드 (예: `HR-9A82-F41C`)
    
- **발급 일시 타임스탬프**: 실제 인쇄/PDF 다운로드 버튼을 누른 정확한 시분초 기록
    
- **스타일**: 최하단 여백 바깥에 `8pt 회색 글씨`로 은은하게 배치
