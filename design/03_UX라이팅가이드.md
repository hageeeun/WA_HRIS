# [UX 라이팅 가이드] 시스템 피드백 및 텍스트 작성 표준 (UX Writing Guide)

> 본 문서는 **HRIS System (Phase 1 MVP)**의 모든 화면, 입력 폼, 피드백 메시지에 사용되는 텍스트의 어조(Tone of Voice)와 데이터 표기 규칙을 정의합니다. 사용자가 시스템을 이용할 때 불필요한 혼란 없이 명확하고 신속하게 업무를 처리할 수 있도록 돕는 실무 가이드라인입니다.

## 1. 개요 및 라이팅 원칙 (Overview & Principles)

### 1.1 시스템 보이스 앤 톤 (Voice & Tone)

- **정중하고 신뢰감 있는 어조 (Courteous & Reliable)**
    
    - 단정하고 신뢰할 수 있는 비즈니스 어조를 유지하며, 정중한 경어체(`~합니다`, `~해 주세요`)를 기본으로 사용합니다.
        
- **군더더기 없는 간결함 (Concise & Direct)**
    
    - 불필요한 수식어나 감정적인 표현을 배제하고, 사용자가 다음 행동을 즉시 파악할 수 있도록 핵심만 전달합니다.
        
- **해결 중심의 안내 (Action-oriented)**
    
    - 에러나 문제가 발생했을 때 단순 상황 보고에 그치지 않고, '사용자가 무엇을 해야 하는지(해결 방법)'를 반드시 함께 안내합니다.
        

### 1.2 3대 문장 작성 원칙

|**원칙 (Principle)**|**나쁜 예시 (Bad)**|**좋은 예시 (Good)**|**작성 기준**|
|---|---|---|---|
|**1. 간결하고 명확하게**|시스템에서 오류가 발생하여 작업을 완료하지 못했습니다.|저장을 완료하지 못했습니다. 잠시 후 다시 시도해 주세요.|불필요한 수식어를 빼고 핵심 상황과 행동만 전달|
|**2. 해결책을 명시**|유효하지 않은 이메일 형식입니다.|이메일 주소 형식이 올바르지 않습니다. (예: user@company.com)|올바른 입력 예시나 구체적 해결 방법 제공|
|**3. 일관된 종결어미**|휴가 신청됨 / 저장되었습니다. / 취소해라|신청이 완료되었습니다. / 저장이 완료되었습니다.|완료형은 `~되었습니다.`, 요청형은 `~해 주세요.`로 통일|

### 1.3 데이터 및 단위 표준 표기 규칙

시스템 전반에서 날짜, 시간, 금액, 수치 데이터를 표기할 때 엄격하게 지켜야 하는 통일 규칙입니다.

|**데이터 항목**|**표기 표준 형식**|**실제 화면 표기 예시**|**세부 적용 규칙**|
|---|---|---|---|
|**날짜 (Date)**|`YYYY.MM.DD`|`2026.08.15`|마침표 뒤 공백 없음|
|**일시 (Date & Time)**|`YYYY.MM.DD HH:mm`|`2026.08.15 09:30`|날짜와 시간 사이 공백 1칸|
|**시간 (Time)**|`HH:mm` (24시간제)|`09:00`, `18:30`|2자리 숫자 표기 (한 자릿수 시 앞에 0 붙임)|
|**기간 (Period)**|`YYYY.MM.DD ~ YYYY.MM.DD`|`2026.09.01 ~ 2026.09.03`|물결표(~) 앞뒤 공백 1칸|
|**금액 (Currency)**|`#,##0 원`|`1,500,000 원`|3자리마다 콤마(,), 숫자와 '원' 사이 공백 1칸|
|**연차 / 일수**|`#.# 일`|`1.0 일`, `0.5 일`, `15.0 일`|반차(0.5) 표기를 고려해 소수점 1자리 통일|
|**전화번호**|`010-XXXX-XXXX`|`010-1234-5678`|하이픈(-) 구분 표기|

## 2. UI 컴포넌트별 텍스트 규칙 (UI Elements)

### 2.1 버튼 및 액션 레이블 (Buttons)

- **기본 원칙**: 버튼을 클릭하거나 터치했을 때 어떤 작업이 일어나는지 명확한 단어(명사형 또는 동사형)로 표현합니다.
    
- **표준 버튼 용어 가이드**:
    

|**버튼 유형**|**표준 버튼 텍스트**|**지양해야 할 표현**|**작성 기준**|
|---|---|---|---|
|**주요 실행 (Primary)**|`로그인`, `출근하기`, `퇴근하기`, `신청하기`, `저장`, `승인`|`OK`, `SUBMIT`, `전송`, `누르기`, `완료`|사용자가 수행할 핵심 액션을 명확히 지칭|
|**보조 / 취소 (Secondary)**|`취소`, `닫기`, `목록으로`, `초기화`|`돌아가기`, `그만두기`, `NO`, `뒤로`|현재 작업을 중단하거나 이전 화면으로 이동|
|**파괴적 실행 (Danger)**|`반려`, `삭제`, `비활성화`|`거부`, `지우기`, `없애기`, `죽이기`|되돌리기 어려운 중요한 작업임을 직관적으로 전달|
|**문서 / 데이터 다운로드**|`PDF 다운로드`, `엑셀 다운로드`, `인쇄`|`파일 받기`, `내보내기`, `출력하기`|다운로드되는 파일 포맷을 명확히 표기|

### 2.2 입력 필드 텍스트 (Forms & Inputs)

#### 1) 입력창 라벨 (Label) 및 필수값 표기

- 라벨은 사용자가 무엇을 입력해야 하는지 알 수 있도록 **명사형**으로 간결하게 작성합니다.
    
    _(예: `성명`, `휴대폰 번호`, `휴가 구분`, `기안 제목`, `품의 금액`)_
    
- 반드시 입력해야 하는 항목은 라벨 오른쪽 끝에 빨간색 별표(`*`)를 붙여 직관적으로 안내합니다.
    
    _(예: `신청 사유 *`, `대표이사 성명 *`)_
    

#### 2) 플레이스홀더 (Placeholder) 표준

입력창 내부에 연한 회색으로 들어가는 힌트 문구 규칙입니다.

|**입력 필드 유형**|**플레이스홀더 표준 문구**|**실제 적용 예시**|
|---|---|---|
|**일반 텍스트 입력**|`내용을 입력해 주세요.` 또는 구체적 예시 표기|`예: 홍길동`, `예: 010-1234-5678`|
|**긴 문장 입력 (Textarea)**|`상세 사유나 내용을 구체적으로 입력해 주세요.`|`휴가 사유 또는 기안 상세 내용을 입력해 주세요.`|
|**선택 / 드롭다운**|`선택해 주세요.`|`부서를 선택해 주세요.`, `휴가 종류를 선택해 주세요.`|
|**날짜 선택 (Datepicker)**|`YYYY.MM.DD`|`2026.08.15`|
|**금액 / 숫자 입력**|`금액을 숫자로 입력해 주세요.`|`예: 1500000 (콤마 없이 입력)`|

### 2.3 입력 유효성 검증 에러 메시지 (Form Errors)

입력값 검증에 실패했을 때 입력창 바로 아래 빨간색 글씨(`12px`)로 나타나는 표준 에러 문구입니다.

| **발생 상황**      | **표준 에러 안내 문구**                              | **해결 안내 포인트**              |
| -------------- | -------------------------------------------- | -------------------------- |
| **필수값 누락**     | `필수 입력 항목입니다.`                               | 입력이 누락된 항목임을 즉시 인지시킴       |
| **이메일 형식 오류**  | `올바른 이메일 형식을 입력해 주세요. (예: user@company.com)` | 올바른 이메일 구조 예시 제공           |
| **비밀번호 규칙 미달** | `비밀번호는 영문, 숫자, 특수문자를 포함해 8자 이상이어야 합니다.`      | 필수 조합 조건(영문/숫자/특수문자/길이) 명시 |
| **비밀번호 불일치**   | `비밀번호가 일치하지 않습니다.`                           | 재입력 비밀번호 불일치 안내            |
| **글자 수 초과**    | `최대 입력 가능한 글자 수({최대 글자}자)를 초과했습니다.`          | 제한 글자 수 명시 (예: 500자 초과)    |
| **금액/숫자 오류**   | `0보다 큰 숫자만 입력해 주세요.`                         | 올바른 숫자 입력 유도               |
| **날짜 순서 오류**   | `종료일은 시작일보다 빠를 수 없습니다.`                      | 기간 설정 시 역전 현상 방지           |

## 3. 시스템 피드백 & 안내 메시지 표준 (System Feedback)

### 3.1 토스트 알림 메시지 (Toast Notifications)

사용자의 작업 완료 또는 주의/에러 발생 시 **화면 상단 중앙에 노출되어 3.0초 동안 유지된 뒤 부드럽게 사라지는** 표준 피드백 문구입니다. 화면의 시각적 통일감을 해치지 않도록 **흰색 카드(`bg-surface`) 기반에 상태 아이콘만 포인트 컬러**를 적용합니다.

| **구분**            | **시각 스타일**                                                                         | **발생 상황**                                                                                                       | **표준 토스트 문구**                                                                                                                                                                      | **비고**                   |
| ----------------- | ---------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| **성공 (Success)**  | • 흰색 배경 (`#FFFFFF`)<br><br>• 기본 텍스트 (`#18181B`)<br><br>• **초록 체크 아이콘 (`#059669`)** | • 휴가/기안 신청 완료<br><br>• 신규 항목 등록 완료<br><br>• 수정/설정 변경 저장<br><br>• 결재 승인 처리<br><br>• 증명서 즉시 발급<br><br>• 직인 이미지 등록 | `신청이 완료되었습니다.`<br><br>`성공적으로 등록되었습니다.`<br><br>`변경사항이 저장되었습니다.`<br><br>`결재가 정상적으로 승인되었습니다.`<br><br>`증명서가 발급되었습니다.`<br><br>`회사 직인이 등록되었습니다.`                                         | 완료형 문장 (`~되었습니다.`) 으로 통일 |
| **에러/주의 (Error)** | • 흰색 배경 (`#FFFFFF`)<br><br>• 기본 텍스트 (`#18181B`)<br><br>• **빨간 경고 아이콘 (`#DC2626`)** | • 가용 잔여 연차 부족<br><br>• 첨부 파일 용량 초과<br><br>• 허용되지 않은 파일 형식<br><br>• 이미 처리된 결재 건<br><br>• 일시적 네트워크/서버 오류          | `잔여 연차가 부족하여 신청할 수 없습니다.`<br><br>`첨부 파일 용량은 최대 10MB까지 가능합니다.`<br><br>`JPG, PNG, PDF 형식의 파일만 업로드할 수 있습니다.`<br><br>`이미 처리가 완료된 결재 문서입니다.`<br><br>`일시적인 오류가 발생했습니다. 잠시 후 다시 시도해 주세요.` | 실패 사유와 함께 구체적 기준 제시      |


### 3.2 작업 확인 모달 문구 (Confirm Modals)

되돌릴 수 없는 파괴적 액션(삭제, 반려 등)이나 결재 승인처럼 명확한 의사결정이 필요한 경우 띄우는 확인 팝업 문구입니다.

```
┌─────────────────────────────────────────────────────────────┐
│ 제목: 결재 문서를 반려하시겠습니까?                          │
├─────────────────────────────────────────────────────────────┤
│ 본문: 반려 처리된 문서는 다시 승인할 수 없습니다.              │
│       반려 사유를 필수로 입력해 주세요.                      │
├─────────────────────────────────────────────────────────────┤
│                                 [ 취소 ]  [ 반려하기 (Red) ]│
└─────────────────────────────────────────────────────────────┘
```

|**작업 유형**|**모달 제목 (Title - 16px SemiBold)**|**본문 안내 문구 (Body - 14px Regular)**|**실행 버튼 레이블**|
|---|---|---|---|
|**결재 승인**|`해당 문서를 승인하시겠습니까?`|`승인 처리 후 대표 직인이 문서에 자동으로 날인되며, 승인 이후에는 내용을 수정할 수 없습니다.`|`[취소]` `[승인하기]`|
|**결재 반려**|`해당 문서를 반려하시겠습니까?`|`반려된 문서는 다시 되돌릴 수 없습니다. 기안자가 확인할 수 있도록 반려 사유를 입력해 주세요.`|`[취소]` `[반려하기]` _(Red)_|
|**휴가 신청 취소**|`휴가 신청을 취소하시겠습니까?`|`신청을 취소하시면 차감되었던 연차가 즉시 복구됩니다.`|`[닫기]` `[신청 취소]` _(Red)_|
|**기안 문서 회수**|`작성 중인 문서를 회수하시겠습니까?`|`문서를 회수하면 결재 대기 상태가 취소되며, 다시 내용을 수정하여 재기안할 수 있습니다.`|`[취소]` `[회수하기]`|
|**계정 비활성화**|`해당 임직원 계정을 비활성화하시겠습니까?`|`비활성화된 계정은 시스템에 로그인할 수 없으며, 기존 근태 및 결재 이력은 그대로 보존됩니다.`|`[취소]` `[비활성화]` _(Red)_|

### 3.3 Empty State 안내 문구 (데이터 없음)

조회된 데이터나 목록이 0건일 때 테이블 중앙 또는 카드 리스트 중앙에 표출되는 표준 안내 영역입니다.

```
┌─────────────────────────────────────────────────────────────┐
│                     [ 40×40 라인 아이콘 ]                   │
│                                                             │
│                    등록된 결재 문서가 없습니다                 │
│               새로운 품의서나 신청서를 기안해 보세요             │
│                                                             │
│                     [ + 신규 문서 작성 ]                    │
└─────────────────────────────────────────────────────────────┘
```

|**화면 및 영역**|**메인 타이틀 (15px SemiBold)**|**서브 설명 문구 (13px Regular)**|**보조 CTA 버튼 (선택)**|
|---|---|---|---|
|**결재 문서함 (대기/완료)**|`등록된 결재 문서가 없습니다.`|`새로운 품의서나 신청서를 기안해 보세요.`|`[ + 신규 문서 작성 ]`|
|**휴가 신청 내역**|`신청한 휴가 내역이 없습니다.`|`휴식이 필요한 날짜를 선택하여 휴가를 신청해 보세요.`|`[ + 휴가 신청하기 ]`|
|**출퇴근 기록 목록**|`해당 기간의 출퇴근 기록이 없습니다.`|`조회 날짜를 변경하거나 기간을 다시 설정해 주세요.`|없음|
|**증명서 발급함**|`발급된 증명서 내역이 없습니다.`|`재직증명서 또는 경력증명서를 즉시 발급받아 보세요.`|`[ + 증명서 신청 ]`|
|**구성원 관리 목록**|`검색 결과와 일치하는 구성원이 없습니다.`|`입력하신 검색어의 철자나 검색 조건을 다시 확인해 주세요.`|`[ 검색 조건 초기화 ]`|

## 4. 기능별 주요 메시지 매트릭스 (HRIS Module Standards)

시스템의 8대 핵심 기능 모듈에서 발생하는 상황별 표준 안내 문구 모음입니다. 기획, 디자인, 프론트엔드 개발 시 이 표의 문구를 그대로 적용합니다.

### 4.1 로그인 & 계정 인증 (로그인/로그아웃)

|**구분**|**상황**|**표준 UX 문구**|**노출 위치**|
|---|---|---|---|
|**안내**|로그인 페이지 진입 시|`회사 이메일 계정으로 로그인해 주세요.`|입력 폼 상단 서브 텍스트|
|**성공**|로그아웃 완료|`안전하게 로그아웃되었습니다.`|로그인 페이지 상단 토스트|
|**에러**|계정 정보 불일치|`이메일 주소 또는 비밀번호가 일치하지 않습니다.`|로그인 버튼 상단 붉은색 안내|
|**에러**|비활성화(퇴사 등) 계정|`비활성화된 계정입니다. 관리자에게 문의해 주세요.`|로그인 버튼 상단 붉은색 안내|
|**에러**|세션 만료|`로그인 시간이 만료되었습니다. 다시 로그인해 주세요.`|모달 팝업 또는 토스트|

### 4.2 근태 관리 (출퇴근 체크 및 직접 정정)

|**구분**|**상황**|**표준 UX 문구**|**노출 위치**|
|---|---|---|---|
|**성공**|출근 버튼 클릭 완료|`정상적으로 출근 처리되었습니다. 오늘도 좋은 하루 보내세요!`|상단 토스트 알림|
|**성공**|퇴근 버튼 클릭 완료|`퇴근 처리되었습니다. 오늘 하루도 수고 많으셨습니다.`|상단 토스트 알림|
|**성공**|출퇴근 시간 직접 수정|`출퇴근 기록이 정정되었습니다. (수정 이력이 안전하게 보관됩니다.)`|모달 닫힘 후 토스트|
|**주의**|당일 이미 출근한 경우|`이미 오늘의 출근 기록이 존재합니다.`|상단 토스트 알림|
|**에러**|미래 시간 입력 시도|`현재 시간 이후의 미래 시간으로는 출퇴근을 기록할 수 없습니다.`|모달 인풋 하단 에러|
|**에러**|퇴근 시간이 출근보다 빠름|`퇴근 시간은 출근 시간 이후여야 합니다.`|모달 인풋 하단 에러|

### 4.3 휴가 관리 (연차 신청 및 잔여일수 조회)

|**구분**|**상황**|**표준 UX 문구**|**노출 위치**|
|---|---|---|---|
|**성공**|휴가 신청 완료|`휴가 신청이 완료되었습니다. 결재 완료 후 최종 확정됩니다.`|상단 토스트 알림|
|**성공**|대기 중인 휴가 취소|`휴가 신청이 취소되었으며, 차감 예정 연차가 정상 복구되었습니다.`|상단 토스트 알림|
|**안내**|주말 포함 기간 선택 시|`신청 기간 내 주말 및 법정공휴일은 연차 차감 일수(0일)에서 자동 제외됩니다.`|신청 모달 하단 안내 문구|
|**에러**|잔여 연차 부족|`신청 가능한 잔여 연차(가용 {잔여일수}일)를 초과하여 신청할 수 없습니다.`|신청 모달 하단 에러 문구|
|**에러**|기간 역전 (종료일 < 시작일)|`휴가 종료일은 시작일보다 빠를 수 없습니다.`|날짜 선택 인풋 하단 에러|

### 4.4 결재 문서 (일반 품의서 / 지출 품의서 / 교육 신청서)

|**구분**|**상황**|**표준 UX 문구**|**노출 위치**|
|---|---|---|---|
|**성공**|결재 문서 기안 완료|`결재 문서가 정상적으로 기안되었습니다.`|상단 토스트 알림|
|**성공**|결재 최종 승인 완료|`문서가 최종 승인되었습니다. 회사 직인이 자동 날인되었습니다.`|상단 토스트 알림|
|**성공**|결재 반려 처리 완료|`문서가 반려 처리되었습니다.`|상단 토스트 알림|
|**성공**|기안 문서 회수 완료|`문서가 회수되었습니다. 내용을 수정하여 다시 기안할 수 있습니다.`|상단 토스트 알림|
|**에러**|반려 사유 미입력|`반려 사유를 필수로 입력해 주세요. (기안자 확인용)`|반려 모달 인풋 하단 에러|
|**에러**|지출 금액 0원 이하 입력|`지출 품의 금액은 1원 이상이어야 합니다.`|금액 인풋 하단 에러|

### 4.5 증명서 발급 (재직 / 경력증명서)

|**구분**|**상황**|**표준 UX 문구**|**노출 위치**|
|---|---|---|---|
|**성공**|증명서 즉시 발급 완료|`증명서가 정상적으로 발급되었습니다. 즉시 인쇄 또는 PDF 저장이 가능합니다.`|상단 토스트 알림|
|**에러**|발급 용도 미입력|`제출처 또는 발급 용도를 입력해 주세요. (예: 금융기관 제출용)`|발급 모달 인풋 하단 에러|
|**에러**|재직 상태 불일치|`재직 중인 구성원만 재직증명서를 발급받을 수 있습니다. (퇴사자는 경력증명서 선택)`|발급 모달 경고 문구|
