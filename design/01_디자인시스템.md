# [디자인 시스템 (Design System)] HRIS System 

## 1. 개요 및 디자인 원칙 (Overview & Principles)

### 1.1 시스템 개요 & 작업 환경

- **시스템명**: HRIS System
    
- **디자인 테마**: **Minimal Monochrome & Functional Color** (무채색 베이스 + 시맨틱 상태 포인트)
    
- **적용 범위**: **반응형 웹 (Responsive Web - Desktop & Mobile Web)**
    
    - **Desktop Web**: Chrome, Safari, Edge, Whale 최신 브라우저
        
    - **Mobile Web**: iOS Safari, Android Chrome 최적화
        
- **디바이스별 해상도 & 브레이크포인트 (Breakpoints)**
    

|**디바이스 구분**|**해상도 범위 (Width)**|**기준 캔버스 규격 (Figma)**|**레이아웃 특이사항**|
|---|---|---|---|
|**Desktop (PC)**|`1280px` 이상|`1440px` (권장: `1920px × 1080px`)|좌측 고정 사이드바(240px), 32px 본문 여백, 데이터 테이블 중심 구조|
|**Tablet**|`768px ~ 1279px`|`834px × 1194px`|유동형 그리드, 접이식 메뉴, 테이블 가로 스크롤 허용|
|**Mobile**|`360px ~ 767px`|`375px × 812px` (최소: `360px`)|상단 헤더 + 드로어(Drawer) 메뉴, 카드형 리스트 전환, 하단 액션바|

- **디자인 툴 환경**: Figma (Auto-layout 5.0, Component Variants, Responsive Constraints, Design Tokens 적용)

### 1.2 4대 UI/UX 디자인 원칙 (Design Principles)

| **원칙 (Principle)**                  | **핵심 정의**                | **실무 적용 기준 (B2B SaaS 표준)**                                                                        |
| ----------------------------------- | ------------------------ | ------------------------------------------------------------------------------------------------- |
| **1. Simplicity (간결성)**             | 불필요한 장식을 배제하고 정보의 본질에 집중 | • 무채색(Black, Gray, White) 중심의 플랫(Flat) & 클린한 면 분할<br><br>• 모바일 환경에서는 뎁스(Depth)를 축소하고 핵심 데이터 우선 배치 |
| **2. Clarity (명확성)**                | 데이터와 처리 상태의 즉각적인 식별      | • 시스템 상태 및 결과 피드백에만 고대비 Semantic 포인트 컬러 적용<br><br>• 인풋 유효성 검증 실패(Red border), 필수 입력값 등 명확한 시각 안내  |
| **3. Consistency (일관성)**            | 멀티 디바이스 환경에서의 균일한 사용자 경험 | • 8px 배수 스페이싱 및 타이포그래피 토큰 100% 재사용<br><br>• PC와 모바일 간 동일한 상태 전이 인터랙션 및 컴포넌트 네이밍 유지                |
| **4. Touch & Efficiency (효율성/접근성)** | 직관적인 조작 동선과 빠른 업무 완결성    | • 모바일 터치 타겟 최소 높이 `44px` 보장 (버튼, 링크, 폼 필드)<br><br>• 불필요한 확인 절차를 줄인 단선 업무 동선 및 키보드/터치 접근성 최적화      |

## 2. 디자인 파운데이션 (Foundations / Design Tokens)

### 2.1 컬러 시스템 (Color Tokens)

전체 인터페이스는 정제된 무채색(Black & Neutral Gray)을 기본으로 사용하여 시각적 피로도를 낮추고, 시스템 상태 피드백에만 **기능적 Semantic 포인트 컬러**를 적용합니다.

#### 1) Brand / Primary Color (Monochromatic)

|**토큰명**|**HEX Code**|**CSS 변수명**|**주요 용도**|
|---|---|---|---|
|`primary-50`|`#F4F4F5`|`--color-primary-50`|활성 탭 배경, 선택 행 연한 배경, 서브 블록|
|`primary-100`|`#E4E4E7`|`--color-primary-100`|컴포넌트 호버 배경, 구분 강조선|
|`primary-700`|`#27272A`|`--color-primary-700`|Primary 버튼 Hover / Pressed 상태|
|**`primary-900`**|**`#18181B`**|**`--color-primary-900`**|**[Main] Primary 버튼, 주요 텍스트, 활성 아이콘**|

#### 2) Status / Semantic Color (기능적 포인트 컬러)

|**상태 / 토큰**|**Point HEX (Text/Icon)**|**Background Tint (10~15%)**|**용도 및 의미**|
|---|---|---|---|
|**대기 (`warning`)**|`#D97706` (Amber-600)|`#FEF3C7` (Amber-100)|처리 대기, 검토 진행 중, 주의 안내|
|**성공/정상 (`success`)**|`#059669` (Emerald-600)|`#D1FAE5` (Emerald-100)|완료/승인, 정상 처리, 성공 토스트 알림|
|**오류/반려 (`danger`)**|`#DC2626` (Red-600)|`#FEE2E2` (Red-100)|요청 반려, 유효성 에러(Red border), 실패/경고|
|**취소/기본 (`neutral`)**|`#4B5563` (Gray-600)|`#F3F4F6` (Gray-100)|본인 취소, 비활성 상태, 중립 서브 태그|
|**안내 (`info`)**|`#2563EB` (Blue-600)|`#EFF6FF` (Blue-50)|시스템 공지, 단순 정보 안내 툴팁|

#### 3) Grayscale & Surface (배경 및 텍스트)

|**토큰명**|**HEX Code**|**주요 적용 대상**|
|---|---|---|
|`text-primary`|`#18181B` (Zinc-900)|본문 텍스트, 페이지 타이틀, 모달 헤더, 테이블 데이터|
|`text-secondary`|`#71717A` (Zinc-500)|보조 설명, 입력창 라벨, 테이블 컬럼 헤더|
|`text-disabled`|`#A1A1AA` (Zinc-400)|Placeholder, 비활성화 텍스트, 비활성 아이콘|
|`border-default`|`#E4E4E7` (Zinc-200)|카드/컨테이너 테두리, 테이블 구분선, 폼 기본 보더|
|`border-focus`|`#18181B` (Zinc-900)|인풋 포커스(Focus) 시 테두리 강조선|
|`bg-app`|`#FAFAFA` (Zinc-50)|전체 웹/모바일 페이지 기본 백그라운드|
|`bg-surface`|`#FFFFFF` (White)|카드 컨테이너, 모달 팝업, LNB 사이드바 배경|

### 2.2 타이포그래피 (Typography)

전체 시스템은 **`Pretendard` 단일 서체**만을 사용하여 완벽한 국/영문 조화와 통일된 시각 계층을 유지합니다.

- **적용 서체**: **`Pretendard` (Pretendard Variable)**
    
- **폰트 렌더링**: `-webkit-font-smoothing: antialiased; -moz-osx-font-smoothing: grayscale;`
    

|**스타일명**|**Desktop 크기**|**Mobile 크기**|**Weight**|**Line-Height**|**자간 (Tracking)**|**주요 사용처**|
|---|---|---|---|---|---|---|
|**Display**|28px|24px|Bold (700)|36px / 32px|-0.02em|시작/로그인 타이틀, 대시보드 메인 타이틀|
|**Page Title**|22px|18px|Bold (700)|30px / 26px|-0.015em|각 화면 최상단 페이지 제목|
|**Section Title**|16px|16px|SemiBold (600)|24px|-0.01em|카드 섹션 헤더, 모달 타이틀|
|**Body (Default)**|14px|14px|Regular (400) / SemiBold (600)|20px|0|본문 내용, 테이블 셀 데이터, 인풋 텍스트, 버튼|
|**Caption (Sub)**|12px|12px|Regular (400) / Medium (500)|16px|0|상태 뱃지, 폼 필드 에러 메시지, 날짜/보조 정보|

### 2.3 스페이싱 & 그리드 (Spacing & Grid)

일관된 여백과 모듈 배치를 위해 8px 배수 시스템 (4px 서브 단위)을 전 화면에 엄격하게 적용합니다.

Plaintext

```
space-1 (4px)   : 뱃지 상하 패딩, 인풋 에러 메시지 상단 간격
space-2 (8px)   : 인라인 아이콘-텍스트 간격, 폼 필드 간 최소 여백
space-3 (12px)  : 버튼 및 텍스트 인풋 내부 상하 패딩
space-4 (16px)  : 카드/모바일 기본 여백, 폼 필드 그룹 간격
space-6 (24px)  : 모달 내부 패딩, 데스크톱 섹션 간 간격
space-8 (32px)  : 데스크톱 본문(Main Contents) 상하좌우 기본 패딩
space-12 (48px) : 대단위 콘텐츠 그룹 구분 여백
```

### 2.4 반응형 레이아웃 규격 (Layout Specifications)

```
[ Desktop Layout (>= 1280px) ]
┌─────────────────┬─────────────────────────────────────────────────────────┐
│ LNB (사이드바)   │ Main Contents Header (Page Title & Profile)             │
│                 ├─────────────────────────────────────────────────────────┤
│ 고정 폭: 240px   │ Contents Canvas (Padding: 32px)                         │
│ 배경: #FFFFFF   │                                                         │
│ 테두리: #E4E4E7 │  ┌───────────────────────────────────────────────────┐  │
│                 │  │ Card Container (Background: #FFFFFF, Radius: 8px)  │  │
└─────────────────┴─────────────────────────────────────────────────────────┘

[ Mobile Layout (< 768px) ]
┌─────────────────────────────────────────────────────────┐
│ Mobile Header (Logo / 햄버거 드로어) [Height: 56px]      │
├─────────────────────────────────────────────────────────┤
│ Main Canvas (Padding: 16px, 수직 스크롤)                │
│  ┌───────────────────────────────────────────────────┐  │
│  │ Mobile Card List (테이블 대체 카드형 리스트)      │  │
│  └───────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────┤
│ Mobile Bottom Action Bar (하단 고정 CTA, Height: 64px)  │
└─────────────────────────────────────────────────────────┘
```

- **Desktop Layout**:
    
    - **사이드바 (LNB)**: 폭 `240px` 고정, 높이 `100vh`, 우측 테두리 `1px solid #E4E4E7`
        
    - **메인 본문**: `Padding: 32px`, 정보 밀도가 높은 데이터 테이블 중심 레이아웃
        
- **Mobile Layout**:
    
    - **상단 헤더**: 높이 `56px` 고정, 슬라이드 아웃 드로어(Drawer) 메뉴 적용
        
    - **메인 본문**: `Padding: 16px`, 가로 스크롤 방지를 위해 테이블 데이터를 **카드형 리스트**로 전환
        
    - **터치 타겟 (Touch Target)**: 모든 인터랙션 요소(버튼, 인풋, 셀렉트) 최소 높이 `44px` 보장
        

### 2.5 라운드, 그림자 및 Z-Index (Radius, Elevation, Layers)

- **Border Radius (모서리 곡률)**:
    
    - `radius-sm (4px)` : 상태 뱃지, 서브 태그, 툴팁
        
    - `radius-md (8px)` : 기본 버튼, 텍스트 인풋, 셀렉트 박스, 카드 컨테이너
        
    - `radius-lg (12px)`: 모달 팝업, 플로팅 다이얼로그
        
    - `radius-full (9999px)`: 원형 프로필 아바타, 토글 스위치
        
- **Elevation & Shadow (미니멀 그림자)**:
    
    - `shadow-sm` (카드 기본): `0 1px 2px 0 rgba(0, 0, 0, 0.05)`
        
    - `shadow-md` (드롭다운/호버): `0 4px 6px -1px rgba(0, 0, 0, 0.08), 0 2px 4px -1px rgba(0, 0, 0, 0.04)`
        
    - `shadow-xl` (모달 팝업): `0 20px 25px -5px rgba(0, 0, 0, 0.1), 0 10px 10px -5px rgba(0, 0, 0, 0.04)`
        
- **Z-Index 계층도**:
    
    - `z-base (0)`: 본문 캔버스
        
    - `z-sticky (100)`: 고정 헤더, LNB 사이드바, 모바일 하단 액션바
        
    - `z-dropdown (200)`: 셀렉트 박스 옵션 리스트, 데이트피커 캘린더
        
    - `z-modal-backdrop (500)`: 모달 배경 딤(`rgba(0, 0, 0, 0.4)`)
        
    - `z-modal (510)`: 모달 팝업 본체, 모바일 사이드 드로어
        
    - `z-toast (1000)`: 화면 최상단 시스템 토스트 알림
        


## 3. 공통 UI 컴포넌트 규격 (UI Components)

### 3.1 버튼 (Buttons)

#### 1) 버튼 스타일 유형

|**버튼 타입**|**배경색 (Background)**|**텍스트/아이콘 색상**|**테두리 (Border)**|**주요 용도**|
|---|---|---|---|---|
|**Primary**|`#18181B` (Zinc-900)|`#FFFFFF`|None|핵심 액션 (제출, 저장, 승인, 확정)|
|**Secondary**|`#FFFFFF`|`#27272A`|`1px solid #E4E4E7`|보조 액션 (취소, 닫기, 이전, 필터 초기화)|
|**Danger**|`#DC2626` (Red-600)|`#FFFFFF`|None|파괴적 액션 (삭제, 반려, 비활성화)|
|**Ghost / Text**|Transparent|`#27272A`|None|목록 내 '상세보기', 팝업 내 인라인 보조 액션|

#### 2) 버튼 크기 및 반응형 규격

- **Large (48px)**: `Height: 48px`, `Padding: 0 20px`, `Font: 15px SemiBold`, `Radius: 8px` (로그인, 메인 CTA)
    
- **Medium (40px) [기본]**: `Height: 40px`, `Padding: 0 16px`, `Font: 14px SemiBold`, `Radius: 8px` (폼 제출, 모달 하단 버튼)
    
- **Small (32px)**: `Height: 32px`, `Padding: 0 12px`, `Font: 12px SemiBold`, `Radius: 6px` (테이블 행 내 서브 액션)
    
- **Mobile 터치 접근성 보장**: 모바일 뷰(`< 768px`)에서는 터치 미스를 방지하기 위해 최소 터치 영역 높이 **`44px`** 이상을 보장합니다.
    

### 3.2 폼 & 입력 필드 (Forms & Inputs)

#### 1) 기본 텍스트 인풋 & 셀렉트 박스 규격

- **높이(Height)**: `40px` (Medium 기본)
    
- **내부 패딩**: `Padding: 10px 14px`
    
- **보더 & 배경**: `Background: #FFFFFF`, `Border: 1px solid #E4E4E7`, `Radius: 8px`
    
- **폰트**: `14px Regular`, `#18181B` (Placeholder: `#A1A1AA`)
    

#### 2) 인풋 상태별 시각 규칙

- **Default**: `Border: 1px solid #E4E4E7`
    
- **Hover**: `Border: 1px solid #71717A`
    
- **Focus**: `Border: 1px solid #18181B`, `Box-shadow: 0 0 0 3px rgba(24, 24, 27, 0.1)` (무채색 포커스 링)
    
- **Error (유효성 검증 실패)**:
    
    - `Border: 1px solid #DC2626` (Red 강조)
        
    - `Box-shadow: 0 0 0 3px rgba(220, 38, 38, 0.1)`
        
    - **하단 에러 텍스트**: 인풋 하단 `4px` 간격, `12px Regular`, `#DC2626` 색상으로 실패 사유 표출
        
- **Disabled**: `Background: #F4F4F5`, `Border: 1px solid #E4E4E7`, `Text: #A1A1AA`, `Cursor: not-allowed`
    

### 3.3 상태 뱃지 (Status Badges)

모든 상태 뱃지는 **`Height: 24px`**, **`Padding: 2px 8px`**, **`Radius: 4px`**, **`Font: 12px SemiBold`** 규격을 공통으로 사용합니다.

|**뱃지 타입**|**배경색 (Bg)**|**텍스트색 (Text)**|**주요 적용 맥락 (Semantic)**|
|---|---|---|---|
|**대기 (`Warning`)**|`#FEF3C7` (Amber-100)|`#D97706` (Amber-600)|처리 대기, 검토 진행 중, 주의 필요|
|**성공/승인 (`Success`)**|`#D1FAE5` (Emerald-100)|`#059669` (Emerald-600)|정상 완료, 승인 확정, 성공 상태|
|**반려/오류 (`Danger`)**|`#FEE2E2` (Red-100)|`#DC2626` (Red-600)|요청 반려, 유효성 실패, 시스템 오류|
|**취소/기본 (`Neutral`)**|`#F3F4F6` (Gray-100)|`#4B5563` (Gray-600)|사용자 취소, 비활성 상태, 중립 태그|
|**정보 (`Info`)**|`#EFF6FF` (Blue-50)|`#2563EB` (Blue-600)|일반 시스템 안내, 툴팁 연계 태그|

### 3.4 데이터 테이블 & 모바일 카드 리스트 (Tables & Lists)

#### 1) Desktop 데이터 테이블 (Table View)

- **컨테이너**: `Border: 1px solid #E4E4E7`, `Radius: 8px`, `Overflow: hidden`
    
- **헤더 (Thead)**: `Height: 44px`, `Background: #FAFAFA`, `Border-bottom: 1px solid #E4E4E7`, `Font: 13px SemiBold`, `Text: #71717A`
    
- **행 (Row - Tbody)**: `Height: 48px`, `Border-bottom: 1px solid #F4F4F5`, `Font: 14px Regular`, `Text: #18181B`
    
- **Hover 효과**: 마우스 오버 시 `Background: #FAFAFA` 즉시 전환
    

#### 2) Mobile 카드형 리스트 (Card List View)

- 모바일 화면(`< 768px`)에서는 데이터 가독성을 위해 테이블을 **카드형 리스트**로 전환합니다.
    
- **카드 구조**: `Background: #FFFFFF`, `Border: 1px solid #E4E4E7`, `Radius: 8px`, `Padding: 16px`, 상하 간격 `12px`
    
- 좌측 상단에 주요 타이틀, 우측 상단에 상태 뱃지, 하단에 핵심 데이터 2단 그리드 정렬
    

### 3.5 모달 & 다이얼로그 (Modals & Dialogs)

#### 1) 레이아웃 구조 (Desktop vs Mobile)

```
[ Desktop Modal Layout (>= 768px) ]
┌─────────────────────────────────────────────────────────────┐
│ Modal Header: Title (16px SemiBold)                                                              [X 버튼]  │
├─────────────────────────────────────────────────────────────┤
│ Modal Body (Padding: 24px)                                                                                           │
│ - 폼 입력 필드 또는 상세 확인 메시지                                                                                     │
├─────────────────────────────────────────────────────────────┤
│ Modal Footer:                   [취소 (선택)]  [저장 (Primary)]│  <-- 우측 정렬 (flex-end)
└─────────────────────────────────────────────────────────────┘

[ Mobile Modal / Bottom Sheet Layout (< 768px) ]
┌─────────────────────────────────────────────────────────────┐
│ Modal Header: Title (16px SemiBold)                                                             [X 버튼]  │
├─────────────────────────────────────────────────────────────┤
│ Modal Body (Padding: 16px, 수직 스크롤)                                                                       │
├─────────────────────────────────────────────────────────────┤
│ [     취소 (Secondary 50%)     ][     확인 (Primary 50%)    ] │  <-- 가로 100% 꽉 찬 분할
└─────────────────────────────────────────────────────────────┘
```

#### 2) 모달 규격 및 정렬 규칙

- **모달 너비 (Width)**:
    
    - **Confirm / Alert (`Small: 440px`)**: 삭제, 반려, 확인 팝업
        
    - **Form / Detail (`Medium: 640px`)**: 상세 데이터 입력 및 신청 모달
        
- **푸터 버튼 정렬 규칙 (Footer Alignment)**:
    
    - **Desktop (PC)**: **오른쪽 정렬 (`justify-content: flex-end; gap: 8px;`)**
        
        $\rightarrow$ 시선 흐름 종료 지점에 액션 배치, `[취소 (Secondary)]` + `[확인/저장 (Primary)]` 순서
        
    - **Mobile (모바일)**: **가로 100% 균등 분할 (`width: 100%; gap: 8px;` 각 버튼 `flex: 1;`)** 또는 상하 적층(Stack)
        
        $\rightarrow$ 엄지손가락 터치 타겟 극대화
        
- **인터랙션 기준**:
    
    - 배경 딤(Dimmed): `Background: rgba(0, 0, 0, 0.4)`, `Z-Index: 500`
        
    - 오픈 시 본문 스크롤 잠금 (`overflow: hidden`), `ESC` 키 또는 `X` 클릭 시 닫기
        

### 3.6 토스트 알림 (Toast Notifications)

- **위치**: 화면 상단 중앙 플로팅 (`Top: 24px`, `Z-Index: 1000`)
    
- **규격**: `Height: 44px`, `Padding: 0 16px`, `Radius: 8px`, `Shadow: shadow-lg`
    
- **동작 규칙**: 노출 후 **`3.0초` 동안 유지된 뒤 부드럽게 페이드아웃(Fade-out)** 소멸
    
- **유형별 스타일**:
    
    - **성공 (Success)**: `Bg: #18181B`, `Text: #FFFFFF` + 체크 포인트 아이콘 ("처리가 완료되었습니다.")
        
    - **에러 (Error)**: `Bg: #DC2626`, `Text: #FFFFFF` + 경고 아이콘 ("입력값을 다시 확인해 주세요.")
        

### 3.7 아바타 & 프로필 컴포넌트 (Avatars)

- **아바타 크기 규격**:
    
    - `32px × 32px` : 테이블 행 및 댓글 인라인 프로필
        
    - `40px × 40px` : 사이드바 하단 / 모바일 상단 헤더 프로필
        
    - `80px × 80px` : 내 정보 / 계정 관리 상세 프로필
        
- **이미지 부재 시 대체(Fallback)**: `#E4E4E7` 무채색 원형 배경 + 사용자 이름 첫 글자(`14px SemiBold, #27272A`) 중앙 배치
    


## 4. 컴포넌트 인터랙션 & 상태 매트릭스 (Interaction States)

### 4.1 6대 공통 인터랙션 상태 정의 (Interaction States Matrix)

사용자의 입력 및 시스템 처리에 따른 컴포넌트의 6대 시각적 변화 규칙입니다.

|**상태 (State)**|**시각적 변화 기준 (CSS Property)**|**PC (Mouse) 동작**|**Mobile (Touch) 동작**|
|---|---|---|---|
|**1. Default**|각 컴포넌트 기본 디자인 토큰 유지|기본 대기 상태|기본 대기 상태|
|**2. Hover**|• 배경색 5~10% 어둡게(`brightness: 0.95`)<br><br>  <br><br>• 테두리 색상 강조 (`#71717A`)|마우스 오버 시 즉각 적용|모바일 미적용 (Sticky Hover 방지)|
|**3. Active / Pressed**|• `transform: scale(0.98)` 미세 축소<br><br>  <br><br>• 배경색 추가 명도 저하|클릭(마우스 다운) 시 피드백|화면 터치(Touch Start) 시 즉각 피드백|
|**4. Focus-visible**|• `Outline: none`<br><br>  <br><br>• `Box-shadow: 0 0 0 3px rgba(24, 24, 27, 0.15)`|키보드 Tab 이동 포커스|폼 필드 터치(Focus) 시 테두리 강조|
|**5. Disabled**|• `Opacity: 0.45`<br><br>  <br><br>• `Cursor: not-allowed`<br><br>  <br><br>• `pointer-events: none`|클릭 불가 및 마우스 커서 금지|터치 이벤트 차단|
|**6. Loading**|• 컴포넌트 내부 텍스트 투명 처리<br><br>  <br><br>• 중앙 로딩 스피너(Spinner) 회전 노출|비동기 API 요청 중 클릭 중복 방지|동일 (추가 터치 방지)|

### 4.2 트랜지션 & 모션 토큰 (Transition & Motion)

빠르고 군더더기 없는 인터랙션을 위해 과도한 애니메이션을 지양하고, **150ms ~ 200ms 단위의 가벼운 마이크로 인터랙션**을 적용합니다.

- **기본 타이밍 함수**: `cubic-bezier(0.4, 0, 0.2, 1)` (Standard Ease-in-out)
    
- **상태 전이 속도**:
    
    - **Fast (100ms ~ 150ms)**: 버튼 Hover/Active, 인풋 포커스 링, 뱃지 전환
        
    - **Base (200ms)**: 드롭다운 옵션 열림, 토스트 메시지 등장/퇴장, 탭 전환
        
    - **Slow (250ms ~ 300ms)**: 모달 팝업 등장/배경 딤(Dim), 모바일 사이드 드로어(Drawer) 슬라이드
        

### 4.3 Empty State (데이터 없음 표출 규격)

테이블, 카드 리스트, 모달 내에 표출할 데이터가 0건일 때 일관된 안내 영역을 렌더링합니다.

#### 1) Empty State 레이아웃 구조

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│                    [ 40×40 라인 아이콘 ]                    │
│                                                             │
│             데이터가 없습니다 (15px SemiBold, #3F3F46)        │
│          조건을 변경하거나 새로운 항목을 등록해 보세요      │
│                     (13px Regular, #71717A)                 │
│                                                             │
│                 [ + 신규 등록 (선택 버튼) ]                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 2) 상세 규격

- **높이(Height)**:
    
    - Desktop 테이블 내부: 최소 `Height: 240px` (세로 중앙 정렬)
        
    - Mobile 카드 리스트: 최소 `Height: 180px`
        
- **시각 요소**:
    
    - **아이콘**: `40px × 40px`, 무채색 라인 아이콘 (`#A1A1AA`)
        
    - **타이틀 (Title)**: `15px SemiBold`, `#3F3F46` (예: "등록된 내역이 없습니다.")
        
    - **설명 (Description)**: `13px Regular`, `#71717A` (예: "필터를 변경하거나 새로운 항목을 추가해 보세요.")
        
    - **선택 CTA 버튼**: `Medium(40px) Primary 또는 Secondary 버튼` (문맥에 따라 배치)
        

### 4.4 로딩 & 스켈레톤 UI (Loading & Skeleton States)

초기 데이터 로딩 시 레이아웃 깜빡임(CLS, Cumulative Layout Shift)을 방지하고 체감 대기 시간을 줄이기 위해 스켈레톤 UI를 적용합니다.

#### 1) 컴포넌트 단위 로더 (Inline Spinner)

- 버튼, 작은 카드 등 단일 액션 로딩 시 사용
    
- **규격**: `16px × 16px` (버튼 내부), `24px × 24px` (모달/컨테이너)
    
- **색상**: 버튼 배경에 맞춰 Primary 버튼은 `#FFFFFF`, 흰색 컨테이너는 `#18181B`
    

#### 2) 스켈레톤 플레이스홀더 (Skeleton Animation)

- 테이블 행(Row) 및 모바일 카드 초기 렌더링 시 실제 컴포넌트와 동일한 크기의 더미 블록 표출
    
- **배경색**: `#F4F4F5`
    
- **애니메이션**: 좌측에서 우측으로 은은하게 빛이 지나가는 펄스 효과 (`1.5s infinite pulse`)
    
- **Radius**: 텍스트 라인은 `radius-sm (4px)`, 아바타는 `radius-full (9999px)` 적용
